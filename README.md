# Dragonwilds Log Diagnostics

In-browser log diagnostic and calibration tool for **RuneScape: Dragonwilds**.

- **Live Application:** [https://coreclk.github.io/dragonwilds-log-analyzer/](https://coreclk.github.io/dragonwilds-log-analyzer/)
- **100% Client-Side:** All log parsing and telemetry calculations run entirely in your browser using Web Workers. Zero log data is ever uploaded or sent over any network.
